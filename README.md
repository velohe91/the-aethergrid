# THE AETHERGRID

> The Aethergrid Interface

> **Grid Node // Protocol in Development.**⚡

The Aethergrid is a cyberpunk digital environment under development — a living node connecting interactive media, Web3 infrastructure, digital collectibles, and the emerging Aethergrid game universe.

It exists within the same visual and creative ecosystem as **VΣLOHE**, but serves a different purpose: where VΣLOHE functions as an exhibition and archive, The Aethergrid is the experimental node where the system begins to become interactive.

---

## 🌐 The Ecosystem

The Aethergrid and VΣLOHE are sister nodes within the same cyberpunk ecosystem.

| Node | Role |
| --- | --- |
| `velohesystem.com` | NFT exhibition / archive |
| `theaethergrid.com` | Game-in-development node + Web3 + Aethergrid Spirits gallery |

The two projects share visual language, assets, and world-building, while remaining distinct experiences.

---

## ⚡ Current Node

The current Aethergrid node includes:

- 🏠 **Boot Landing** — entry point into the grid
- 👻 **Aethergrid Spirits** — digital collectible gallery
- 📡 **Protocol** — experimental protocol node currently in development
- 🔗 **CONNECT NODE** — Web3 wallet connection interface
- 💠 **Ethereum + Base** — currently supported wallet networks
- 📈 **ETH Live Feed** — real-time ETH market ticker
- 🧬 **Web3 infrastructure** — wallet connectivity and chain-aware application architecture

This repository represents an evolving development state. Features may change as the Aethergrid protocol and game system continue to take shape.
